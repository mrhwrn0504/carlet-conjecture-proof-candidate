# Carlet v7: 直接消去 $t_r$ 的代数形式化设计

**状态：待确认；本文件不是 Lean 实现或验收结果。**

## 目标

把满秩层二次模型的代数部分形式化为 Lean 4 + Mathlib。固定采用 v7 的直接消去 $t_r$ 方案；不采用引入额外 $s_i$、$v_{a,j}$ 的替代坐标方案。每个代数引理都必须有独立陈述和独立证明，不能把尚未证明的几何结论作为假设。

## 数学模型

令 $m_r=\binom r2$。从 v6 已约化的模型出发（即已经没有 $d_i$ 逆元变量），原坐标为
- $u_{a,j}$，其中 $2\le a\le r$、$1\le j<a$；
- $t_2,\ldots,t_r$；
- $c_1,\ldots,c_{r-1}$。

约定 $t_1=1$、$u_{a,a}=1$。原关系为
\[
u_{a,j}^2+u_{a,j}=c_j u_{a,j+1},\qquad
c_jt_{j+1}=t_j,\qquad
1+\sum_{i=2}^{r}t_i=0.
\]

定义仅作为多项式表达式、而非新坐标变量的
\[
T_r^*:=1+\sum_{i=2}^{r-1}t_i.
\]
在特征二中，最后一个总和关系等价于 $t_r=T_r^*$。将最后一条比例关系 $c_{r-1}t_r=t_{r-1}$ 直接代入，得到 v7 模型：
\[
u_{a,j}^2+u_{a,j}=c_j u_{a,j+1},
\]
\[
c_jt_{j+1}=t_j\quad(1\le j<r-1),
\]
\[
c_{r-1}\left(1+\sum_{i=2}^{r-1}t_i\right)=t_{r-1}.
\]
因此 v7 的坐标只有 $u_{a,j}$、$t_2,\ldots,t_{r-1}$、$c_1,\ldots,c_{r-1}$；不引入任何 $s_i$ 或 $v_{a,j}$。

边界 $r=2$ 必须覆盖：空和按 $0$ 解释，此时最后一条关系化为 $c_1=1$。

变量数和关系数分别为
\[
N_r^{(7)}=\binom r2+2r-3,\qquad
R_r^{(7)}=\binom r2+r-1,
\]
故 $N_r^{(7)}-R_r^{(7)}=r-2$。所有关系仍为次数至多二的多项式关系。

## 方案比较

1. **保留 $t_r$**：直接形式化原约化模型，接口最接近 v6，但没有落实本轮指定的 v7 消元。
2. **直接消去 $t_r$（选定）**：由特征二总和关系解出 $t_r=T_r^*$，代入唯一剩余的末端比例关系。只删除一个坐标，保留原有 $u,t,c$ 变量和三角方程；证明负担最小，且消元映射有显式多项式逆。
3. **增加辅助坐标**：引入额外中间变量重写递推。此方案会扩大坐标和证明接口，与本轮固定选择不符，不采用。

## 证明分解与文件边界

- `Carlet/QuadraticV7Elimination.lean`：在任意 `ZMod 2`-代数中独立证明总和关系与 $t_r=T_r^*$ 等价；构造遗忘 $t_r$ 和补回 $t_r$ 的映射，证明互逆及对基代数映射的自然性。
- `Carlet/QuadraticV7Units.lean`：从比例链独立推出 $t_i\prod_{j<i}c_j=1$；证明相关 $t_i$ 为单位，并从末端关系推出 $T_r^*$ 与 $c_{r-1}$ 为单位；另证有限乘积为单位则每个因子为单位。
- `Carlet/QuadraticV7Reconstruction.lean`：独立证明子空间多项式递推、系数递推和三角坐标归纳式 $L_{j-1}(x_a)=\delta_j u_{a,j}$；再证明单位条件足以保证所有非零二元线性组合为单位。
- `Carlet/QuadraticV7.lean`：汇总已证明的代数接口；不得把几何、上同调或点数结论写成公理。

每个公共定理旁都给出 `#print axioms`。如某条引理暂时无法证明，应保留为未完成工作并停止该依赖链，不得用 `sorry`、`admit`、自建公理或不透明占位定理替代。
